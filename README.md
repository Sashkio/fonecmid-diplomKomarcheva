# Инструкция по начальной настройке обновленной базы данных "Ваш компьютерный мастер"
## Безопасность
 Для соответствия должностям пользователей, а также для обеспечения безопасности данных, сохранения конфиденциальности информации в обновленной базе предусмотрены новые профили доступа
  - Менеджер - для работы с заявками клиентов, планирования работ
  - Специалист - для регистрации выполненных им работ, а также контроля за собственной выработкой
  - Бухгалтер - для формирования актов выполненных работ и их анализа по отчету
  - Кадровиков - для работы с начислением и выплатой заработной платы, расчета отпусков сотрудников, планирования графиков этих отпусков.

 Для дальнейшей работы с вышеуказанными профилями доступа необходимо добавить одноименных пользователей и назначить им данные роли. 

## Работа с заявками клиентов

Для удобства регистрации и обработки заявок в базу добавлен документ "Обслуживание клиентов", введены печатные формы реализаций, а также реализован функционал массового создания актов за месяц.
Для корректности работы подсистемы необходимо:
 - Заполнить константы "НоменклатураАбонентскаяПлата" и "НоменклатураРаботыСпециалиста"
   
## Работа с заработной платой

 Для удобства работы с графиками работы сотрудников добавлена обработка автоматического заполнения графиков. Необходимо:
  - Добавить нужный график работы в регистр "Графики работы"
  - В обработке "Заполнение графика" выбрать нужный график, прописать цифрами выходные дни в поле "Выходные дни" (например, 6, 7 - суббота, воскресенье)
  - Выбрать нужный период и нажать кнопку "Заполнить"

 Помимо графиков необходимо заполнить данные в регистр "Условия оплаты сотрудников.
 
 ## Работа с отчетами

 Так как все отчеты работают на основании данных регистров, информация будет доступна только после проведения документов
 - Отчеты по выработке специалистов и взаиморасчетам с сотрудниками формируйте после проведения документа "Обслуживание клиентов"
 - Отчет об анализе выставленных актов - после работы обработки "Массовое создание актов"
 - Для отчета об анализе отпусков необходимо заполнить график планируемых отпусков.

# Подготовка информационной базы к автотестированию
 
## Установка Vanessa Automation

- Скачайте Vanessa Automation из [официального гит-репозитория](https://pr-mex.github.io/vanessa-automation/dev/).
- Создайте "пустую" базу 1С и запустите ее с параметром /TESTMANAGER - далее Менеджер тестирования
- После запуска менеджера тестирования через открытие файлов откройте скачанный файл с Vanessa Automation с расширением .epf
- Ознакомтиесь с обучающей иформацией
- Скопируйте адрес Вашей обновленной базы
- В Vanessa Automation на вкладке "Клиенты тестирования" добавьте нового клиента, вставив скопированный адрес

## Подготовка инфомационной базы

 - Отредактируйте обновленную информационную базу - добавьте параметр запуска /TESTCLIENT - далее Клиент тестирования
   
## Запуск автотеста
 Необходимо запускать тесты в соответствующей инструкции последовательности
 - Открыть фича-файл с именем "Менеджер" и запустить его
 - Октрыть фича-файл с именем "Специалист" и запустить его
 - Открыть фича-файл с именем "Бухгалтер" и запустить его
